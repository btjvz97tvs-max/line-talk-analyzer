# トーク分析

LINEのトーク履歴（`.txt`）を読み込んで、メッセージ数の推移や時間帯、連続日数、よく使う言葉などをスマホサイズの画面で眺められる、**ブラウザだけで動くWebアプリ**です。

> LINE公式のツールではありません（非公式の個人制作です）。「LINE」はLINEヤフー株式会社の商標です。

## できること

| ページ | 内容 |
| --- | --- |
| 概要 | 期間（1週間〜全期間）を切り替えながら、メッセージ数の推移を表示 |
| 詳細 | 日ごとの件数・文字数 |
| 履歴 | 日ごとの一覧、お気に入り・メモ、ランダム思い出 |
| 記録 | 連続で話した日数などの記録 |
| 時間帯 | 時間帯ごとの傾向 |
| 内訳 | 言葉・絵文字のランキング、返信速度、話題の傾向 |
| カレンダー | 日ごとの多さをカレンダーで表示 |
| 検索 | トーク全体のキーワード検索 |
| 月次 / 比較 | 月ごとの推移、ふたりの比較 |
| シェア | 画像カードを作って共有・保存 |
| 再生 | トークを1通ずつ再生（期間と速さを選べます） |

## 使い方

1. LINEのトーク画面から「トーク履歴を送信」で、テキストファイル（`.txt`）として書き出します（メニューの名前はLINEのバージョンで少し違うことがあります）。
2. ページを開いて、そのファイルを選びます。

動作確認用に、架空のトークを `sample/sample_chat.txt` に置いています。

## プライバシー

- 読み込んだトークは**ブラウザの中だけで処理**します。アプリのコードにはトーク内容を外へ送る処理はありません。
- ただしページを開くとき、部品（React / Recharts）を jsDelivr から、フォントを Google Fonts から読み込みます。この通信は発生します。
- ブラウザの `localStorage` に、テーマ設定・目標値・日付ごとのお気に入りとメモを保存します（トーク名と参加者名をキーにしています）。トーク本文そのものは保存しません。

## 自分で動かす

`index.html` は単体で動くので、そのままブラウザで開けます（インターネット接続が必要です）。

### GitHub Pages で公開する

リポジトリの **Settings → Pages** で、Branch を `main`、フォルダを `/ (root)` にすると、`index.html` がそのまま公開されます。

### 修正してビルドする

画面のコードは `src/app.jsx`、ページの外枠は `src/template.html` です。変更したら次で `index.html` を作り直します。

```sh
npm install
npm run build
```

## 注意

- 実際のトーク履歴（`.txt`）は、他の人のメッセージも含みます。リポジトリに入れたり、Issueに貼ったりしないでください（`.gitignore` で `.txt` は除外しています）。
- 音や共有・保存の動きは、端末やブラウザによって差があります。
